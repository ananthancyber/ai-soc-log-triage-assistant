# AI SOC Log Triage Assistant

## Overview

The AI SOC Log Triage Assistant is a cybersecurity project that uses Artificial Intelligence to assist Security Operations Center (SOC) analysts in understanding and prioritizing security alerts generated by Wazuh SIEM.

The project processes real Wazuh security alerts, extracts security-relevant information using Python, and prepares the data for AI-assisted analysis using a locally hosted Large Language Model (LLM) through Ollama.

The long-term objective is to generate structured incident summaries, identify potential attack techniques, and provide investigation recommendations while keeping all security data on the local machine for privacy.

## Development Philosophy

Rather than only presenting the final project, this repository documents the complete development journey. Each milestone includes implementation details, challenges encountered, solutions applied, and the concepts learned throughout the project.

The security alerts used during development are generated from my own Wazuh Blue Team Detection Lab, allowing the AI pipeline to be built and tested using realistic security events instead of synthetic examples.
