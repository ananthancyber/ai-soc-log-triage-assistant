# AI SOC Log Triage Assistant

## Overview

The AI SOC Log Triage Assistant is a cybersecurity project that uses Artificial Intelligence to assist Security Operations Center (SOC) analysts in understanding and prioritizing security alerts generated by Wazuh SIEM.

Instead of manually reviewing hundreds of log entries, the assistant retrieves relevant security events, analyzes them using a local Large Language Model (LLM), and generates structured incident summaries with investigation recommendations.

The project uses Retrieval-Augmented Generation (RAG), a local LLM through Ollama, and Python to provide privacy-focused AI-assisted security analysis without sending log data to external cloud services.
