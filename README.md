# AI SOC Log Triage Assistant

## Overview

The AI SOC Log Triage Assistant is a cybersecurity project designed to assist Security Operations Center (SOC) analysts in triaging and investigating security alerts generated by Wazuh SIEM using Artificial Intelligence.

The application processes real Wazuh security alerts, extracts security-relevant information with Python, and analyzes each alert using a locally hosted Large Language Model (LLM) through Ollama. The generated analysis is automatically compiled into structured Markdown reports for security investigations.

The project is built with a privacy-first approach—keeping all security data and AI processing on the local machine without relying on external cloud services.

The long-term objective is to combine Retrieval-Augmented Generation (RAG), MITRE ATT&CK knowledge, and local AI models to provide accurate, explainable, and actionable SOC investigation assistance.

# Development Philosophy

This repository documents the complete engineering journey of building an AI-assisted SOC investigation tool rather than presenting only a finished application.

Each development milestone includes:

- Design decisions
- Implementation details
- Challenges encountered
- Solutions applied
- Security concepts learned
- Testing and validation

The project emphasizes maintainable software engineering practices alongside cybersecurity concepts, ensuring the application evolves into a modular, extensible, and production-oriented solution.

All security alerts used throughout development originate from my own Wazuh Blue Team Detection Lab, enabling the AI workflow to be built and evaluated using realistic security events generated within a controlled environment.
