# SOC Investigation Guide

## Initial Investigation

When investigating a security alert, analysts should:

- Review the alert details.
- Identify the affected host or user.
- Check the source IP address.
- Determine whether similar alerts have occurred recently.
- Correlate related security events.
- Review authentication and system logs.

---

## Investigation Questions

- Is this activity expected?
- Has this source IP been seen before?
- Did the attack succeed?
- Are multiple systems affected?
- Is escalation required?

---

## Best Practices

A single alert should not be treated as a confirmed security incident.

Analysts should gather additional evidence before determining whether malicious activity has occurred.
